# StatusbarLog has moved to Codeberg

This repository is no longer maintained on GitHub. Development, issues,
releases, and documentation have moved to **Codeberg**:

### 👉 https://codeberg.org/lwidm/statusbarlog

Please update your bookmarks, remotes, and submodules.

## Update an existing clone

```sh
git remote set-url origin ssh://git@codeberg.org/lwidm/statusbarlog.git
```

## Add as a submodule

```sh
git submodule add ssh://git@codeberg.org/lwidm/statusbarlog.git statusbarlog
```
